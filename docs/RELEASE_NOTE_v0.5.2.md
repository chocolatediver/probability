# Release Note v0.5.2

Date: 2026-07-06

## Summary
v0.5.2는 Streamlit 대시보드를 컴포넌트 기반 구조로 재작성한 Dashboard Framework 버전입니다.

## Added
- Market Selector
- Status Cards
- Chart Panel
- Performance Card
- DuckDB Explorer
- OrderBook Panel
- Log Panel

## Run

```bash
streamlit run dashboard/streamlit_app.py
```
